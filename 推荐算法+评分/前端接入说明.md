# recommendation_v2 前端接入

静态网页不能直接执行 Python，因此当前 Demo 采用“Python 产出结果，浏览器消费结果”的方式接入：

1. `scoring_v2` 生成前测评分结果。
2. `recommendation_v2` 结合六维视频标签、安全规则和历史记录生成推荐结果。
3. `tools/build-recommendation-catalog.py` 把评分、推荐、样本来源和视频标签整理为 `assets/data/recommendation-catalog-v2.json`，并将 12 个素材视频复制到 `assets/video/library/`。
4. `recommendation-service.js` 在浏览器中读取目录，将推荐的 `video_id` 映射到实际 MP4。

默认演示样本为模拟前测 `U002`。访问 `/?sample=U001` 可验证唯一的真实提取前测；`U001` 的后测依然是模拟数据。

算法或标签更新后，在项目根目录运行：

```powershell
python tools\build-recommendation-catalog.py
```

正式接入服务器时，可以让后端运行同一套 Python 评分与推荐模块，并返回与 `recommendation-service.js` 当前计划对象相同的字段；前端页面和视频播放器不需要重写。
