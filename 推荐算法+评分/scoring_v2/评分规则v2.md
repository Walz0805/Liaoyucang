# 疗愈前后评分规则 v2

> 规则版本：`score_v2`  
> 适用场景：一次约 25 分钟 VR 疗愈会话的即时状态与前后变化评估  
> 边界：本规则用于状态评估与产品反馈，不替代临床诊断。

## 1. 核心原则

评分分为三个相互隔离的层次：

1. **特质/症状基线层**：PHQ-9、GAD-7、HAMA、SCL-90、MHT、COPA-PI。用于分诊、安全门控、个性化和跨会话长期追踪，不进入一次 25 分钟会话的前后变化分。
2. **即时状态层**：STAI-S、VAS 情绪、SAM 效价，以及由设备表情通道计算的辅助情绪信号。疗愈前后各测一次；量表是主要证据，合格表情作为 `mood` 的辅助证据。
3. **连续生理层**：心率、呼吸、皮电，以及设备能够提供时的 IBI/RR-HRV。提供生理状态和过程信息。体温、血氧、眼动、头动和脑电作为质量、过程或扩展指标，不直接进入当前核心合成分（因为理论支撑不足）。

以下限制是硬规则：

- PHQ-9 测量过去两周，不得作为同一会话即时前后测，也不得进入 `state_change`。
- 普通心率序列不是 IBI/RR，禁止由心率序列反推 HRV。
- 表情只能使用 `生理数据.txt` 实际提供的 `time/x/y/value`；质量不合格时不计分。若未来平台明确标记头显沉浸阶段，则该阶段禁用表情。
- 缺失指标不记 0 分，只按实际有效权重重归一化。
- 前后指标集合不一致时，只使用两次共同有效指标计算变化分。

## 2. 输入数据

### 2.1 前后测数据集

评分分两次执行。推荐前只接收前测文件：

```powershell
python scoring_v2.py --mode befor --input before.json --output scoring_v2_results_befor.json
```

该输出只能包含前测评分，不出现后测数据或前后对比。推荐完成后只接收后测原始文件，并读取已保存的前测评分：

```powershell
python scoring_v2.py --mode after --input after.json --before-scores scoring_v2_results_befor.json --output scoring_v2_results_after.json
```

后测输出包含后测评分，并使用前测评分文件计算前后对比；后测阶段不重新读取前测原始数据。

数据集结构：

```json
{
  "version": "v2_input_schema",
  "samples": [
    {
      "sample_id": "U001",
      "before_sample_id": "U001",
      "assessment_stage": "before",
      "state_measures": {
        "stai_s_total": 42,
        "vas_mood": 6.5,
        "sam_valence": 6,
        "sam_arousal": 4
      },
      "scales": {
        "phq9_total": 9,
        "gad7_total": 7
      },
      "physiology": {
        "msg": "操作成功",
        "code": 200,
        "data": [],
        "nextStartTime": "2026-06-24 15:14:22"
      }
    }
  ]
}
```

后测样本使用 `before_sample_id` 与前测样本配对。若两个文件样本数量相同且没有该字段，程序按位置配对；正式数据必须提供稳定 ID，不建议依赖位置。

### 2.2 状态量表字段

| 字段 | 合法范围 | 说明 |
| --- | ---: | --- |
| `stai_s_total` 或 `stai_s` | 20-80 | STAI 状态焦虑总分，越高越焦虑 |
| `vas_mood` 或 `vas_emotion` | 0-10 | 当下情绪，0 最差、10 最好 |
| `sam_valence` | 1-9 | 标准 SAM 效价 |
| `sam_valence_0_10` | 0-10 | 项目采用 0-10 界面时使用的显式字段 |
| `sam_arousal` | 1-9 | SAM 唤醒，单列输出 |
| `sam_arousal_0_10` | 0-10 | 0-10 界面的 SAM 唤醒，单列输出 |

不得把 0-10 的 SAM 值写入标准 `sam_valence` 字段。若 VAS 和 SAM 效价同时存在，先分别映射到 0-100，再取算术平均形成一个 `mood` 分项，避免重复增加主观情绪权重。

### 2.3 结构化生理数据

`physiology` 必须使用真实 `生理数据.txt` 的通道结构：

```json
{
  "msg": "操作成功",
  "code": 200,
  "data": [
    {
      "label": "心率",
      "preValue": "73.4",
      "maxValue": "97.0",
      "minValue": "62.0",
      "dateValues": [
        {"time": "15:13:39.911", "x": null, "y": null, "z": null, "value": "72.0"}
      ],
      "dateType": 1
    }
  ],
  "nextStartTime": "2026-06-15 15:29:03"
}
```

程序按 `label` 和 `dateType` 双重识别通道。数值字符串会转换为有限浮点数，无法转换、无穷或 NaN 均视为非法。

| 通道 | `dateType` | 当前用途 |
| --- | ---: | --- |
| 心率 | 1 | 生理状态分 |
| 呼吸 | 2 | 生理状态分 |
| 体温 | 3 | 合理性检查，不计分 |
| 眼动 | 4 | 过程/推荐扩展，不计核心分 |
| 表情 | 5 | 质量合格时作为 `mood` 的辅助信号 |
| 加速度 | 11 | 头动过程指标，不计核心分 |
| 角速度 | 12 | 头动过程指标，不计核心分 |
| Delta/Theta | 21/22 | 扩展指标，不计核心分 |
| Alpha/Beta/Gamma | 23/24/25 | 扩展指标，不计核心分 |
| 皮电 | 31 | 生理状态分/交感唤醒代理 |
| 血氧 | 41 | 有效性检查，不计分 |
| 温湿度 | 61 | 环境背景，不计分 |
| IBI/RR | 6/7 或指定标签 | HRV，设备提供时启用 |

程序也可读取首行是说明文字、后续为 JSON 的真实 `.txt`，但前后变化仍需要两个可配对的测量文件。

## 3. 状态量表映射

所有计分项统一映射到 0-100，分数越高表示当下状态越好。

```text
STAI-S状态分 = (80 - stai_s_total) / 60 × 100
VAS情绪分    = vas_mood × 10
SAM效价分    = (sam_valence - 1) / 8 × 100
SAM效价0-10  = sam_valence_0_10 × 10
注：SAM量表采用不同的打分方式时，需根据实际选择映射方式。
```

超出合法范围的值不截断成边界值，而是剔除并写入 `invalid_input`，避免错误输入伪装成有效极值。

SAM 唤醒不进入合成分。高唤醒可能是焦虑，也可能是积极兴奋，不能只凭数值高低判断状态好坏。

主观情绪分先取有效 VAS/SAM 效价分的算术平均。表情分的计算见第9节。最终 `mood` 为：

```text
主观情绪和表情都有效：mood = 0.70 × subjective_mood + 0.30 × expression_score
只有主观情绪有效：    mood = subjective_mood
只有表情有效：        mood = expression_score
两者都无效：          mood = null
```

表情不作为独立的核心分项，因此不会在 `state_weights` 中增加新的权重。

## 4. 连续生理评分

### 4.1 数据质量

每个通道先执行：

1. 字符串转有限数值；
2. 生理量程过滤；
3. 计算有效率、时长、均值、总体标准差和相邻重复率；
4. 有效率低于 0.80 时，该通道不计分；
5. 窗口短于 30 秒时标记 `window_too_short`；
6. 相邻重复率不低于 0.90 时标记 `quantized_or_flat_*`。

相邻重复率只作为质量提醒，不直接扣分。真实设备的心率和呼吸存在明显整数化，v2 不再使用未经校准的 CV 稳定性分。

### 4.2 生理量程和目标区间

| 指标 | 有效量程 | 目标区间 | 超出目标后的线性容忍范围 | 生理分权重 |
| --- | --- | --- | --- | ---: |
| 心率 | 30-220 次/分 | 60-80 | 下侧10，上侧20 | 0.35 |
| 呼吸 | 4-60 次/分 | 10-18 | 下侧4，上侧8 | 0.35 |
| 皮电 | 0-100 | 1-10 | 下侧1，上侧15 | 0.30 |

区间评分：目标区间内为100；超出后按容忍距离线性降至0。

```text
physiology_score = weighted_mean([HR分, 呼吸分, 皮电分], [0.35, 0.35, 0.30])
```

皮电绝对值高度依赖设备和个体，当前目标区间只是初始工程配置，必须通过真实数据标定。输出中保留全部质量统计以便后续替换。

### 4.3 体温和血氧

- 体温只接受 30-43℃，用于设备合理性检查，不代表短时疗效。
- 血氧只接受 70%-100%；低于70的值作为伪影剔除并标记 `spo2_artifact_removed`。
- 两者均不进入 `physiology_score`。

## 5. HRV

HRV 只接受毫秒单位的 IBI/RR 间期流：

- 合法间期：300-2000 ms；
- 最少30个有效间期；
- 有效率不低于0.80；
- 当前计算 `RMSSD` 和 `lnRMSSD`。

```text
RMSSD = sqrt(Σ(IBI[i+1] - IBI[i])² / (n-1))
lnRMSSD = ln(RMSSD)
HRV分 = clamp((lnRMSSD - 2.5) / (4.5 - 2.5) × 100, 0, 100)
```

`[2.5, 4.5]` 是待真实样本校准的初始参考范围。没有 IBI/RR 时：

- `hrv.score = null`；
- 写入 `hrv_unavailable`；
- 不使用普通心率序列替代；
- 合成分按剩余有效权重重归一化。

## 6. 表情辅助信号

表情通道按 `dateType=5` 或 `label=表情数据` 识别。当前只使用 `生理数据.txt` 实际提供的字段：

```text
time：采样时间
x：积极/中性/消极方向
y：具体表情类别
value：设备表情编码
```

七类表情建立以下映射：

| `x`  | `y`  | `value` | 标准类别   |
| ---- | ---- | ------: | ---------- |
| 积极 | 高兴 |       2 | `happy`    |
| 积极 | 惊讶 |       1 | `surprise` |
| 中性 | 中性 |       0 | `neutral`  |
| 消极 | 悲伤 |      -1 | `sadness`  |
| 消极 | 厌恶 |      -2 | `disgust`  |
| 消极 | 恐惧 |      -3 | `fear`     |
| 消极 | 愤怒 |      -4 | `anger`    |

由原始记录计算：总数、有效数、有效率、持续时间、类别分布、平均设备值和相邻重复率。表情参与评分的最低条件为：

```text
raw_count >= 10 // 记录数
valid_count >= 10 // 有效记录数
valid_ratio >= 0.80 // 有效记录比例
duration_sec >= 10 // 记录时长
```

未知类别和编码不一致记录会从有效记录中排除，并保留质量标记。相邻重复率不低于 `0.90` 时标记 `expression_high_repeat`，但不直接判为无效，因为持续中性可能是真实状态，也可能是设备重复输出，当前字段无法进一步区分。

`value`到表情得分的映射：

```text
mean_device_value = 有效value的算术平均
expression_score = clamp((mean_device_value + 4) / 6 × 100, 0, 100)
```

表情只通过第3节公式作为 `mood` 的辅助信号，不作为独立核心分项：

```text
主观情绪和表情都有效：mood = 0.70 × subjective_mood + 0.30 × expression_score
只有主观情绪有效：    mood = subjective_mood
只有表情有效：        mood = expression_score
两者都无效：          mood = null
```

## 7. 综合状态分

```text
state_score = weighted_mean(
  [STAI-S状态分, mood情绪分, physiology_score, HRV分],
  [0.30, 0.25, 0.35, 0.10]
)
```

任何缺失项均不记0分。例：HRV 缺失时，其他三项的有效权重总和0.90，分母使用0.90。

数据质量分级：

- `good`：至少3个核心分项有效；
- `fair`：1-2个核心分项有效；
- `invalid`：没有核心分项有效。

## 8. 前后变化与可比性

不得直接相减由不同指标集合合成的前后总分。v2 先取得前后共同有效指标，再使用共同权重分别重算：

```text
common_metrics = 前测有效指标 ∩ 后测有效指标
common_mood_sources = 前测mood来源 ∩ 后测mood来源
前后mood先按共同来源分别重算
before_common_score = weighted_mean(前测共同指标, 对应权重)
after_common_score  = weighted_mean(后测共同指标, 对应权重)
state_change = after_common_score - before_common_score
```

没有共同指标时：`state_change=null`、`comparable=false`，并标记 `data_insufficient_for_change`。

效果等级：

| 变化分 | 标签 |
| ---: | --- |
| ≥15 | 明显改善 |
| 5 至 <15 | 轻度改善 |
| -5 至 <5 | 基本稳定 |
| -15 至 ≤-5 | 轻度下降 |
| ≤-15 | 明显下降 |

阈值是初始配置，尚未由临床样本校准。

## 9. PHQ-9 和其他基线量表

`scales` 与输入中的 `baseline_context` 合并保存到输出 `baseline_context`。PHQ-9、GAD-7、HAMA、SCL-90、MHT、COPA-PI：

- 不进入 `state_score`；
- 不进入 `state_change`；
- `phq9_change` 始终为 `null`；
- 可供风险门控和推荐算法使用；
- 跨会话长期追踪必须另设时间尺度，不能解释为本次短时疗效。

## 10. 即时文本反馈

评估报告摘要不进入疗效分。用户疗愈后的即时自述只用于识别安全风险，例如：

- 强烈不适、严重头晕、胸闷、恶心；
- 更焦虑、更难受、明显恶化；
- 无法继续、必须停止、要求停止。

命中时输出 `negative_reaction`；涉及身体强烈不适或中断会话时输出 `critical_risk`。文本不影响 `state_score`，避免把规则词典意见当作状态量表。

## 11. 风险和质量标记

| 标记 | 含义 |
| --- | --- |
| `invalid_input` | 状态量表越界或没有有效评分输入 |
| `missing_data` | 没有任何核心分项 |
| `hrv_unavailable` | 无有效 IBI/RR，不能计算 HRV |
| `window_too_short` | 生理窗口短于30秒 |
| `low_valid_ratio_*` | 指定通道有效率不足0.80 |
| `quantized_or_flat_*` | 通道高度重复或平坦 |
| `temperature_artifact_removed` | 非法体温被剔除 |
| `spo2_artifact_removed` | 非法血氧被剔除 |
| `expression_unavailable_in_immersion` | 沉浸期表情不可用 |
| `expression_high_repeat` | 表情相邻重复率较高，仅作质量提醒 |
| `expression_unknown_labels` | 表情通道含未知类别 |
| `expression_inconsistent_records` | `x/y/value` 编码组合不一致 |
| `negative_reaction` | 即时文本出现负面反应 |
| `critical_risk` | 强烈身体不适或要求中止 |
| `data_insufficient_for_change` | 无共同前后指标，无法计算变化 |

风险标记不能被“综合分改善”覆盖，应独立展示。

## 13. 配置、审计与校准

权重、目标区间、量程、质量阈值、HRV参考范围和效果阈值集中保存在实现的 `CONFIG` 中，并随输出保存。每次评分保留：

- 原始状态量表值及映射后分数；
- 实际参与合成的指标；
- 各生理通道原始点数、有效点数、有效率、时长、均值、标准差和重复率；
- HRV 的 RMSSD、lnRMSSD 和质量信息；
- 表情原始计数、有效率、分布、平均设备值、质量标记及其是否参与 `mood`；
- `mood` 的主观来源、表情来源及映射后分数；
- 前后共同指标与共同口径分数；
- 即时反馈证据和全部风险标记。

当前权重和阈值属于工程初始值。获得足够的真实前后配对数据后，应通过预注册的标定流程更新配置，并保留历史版本结果；规则主版本仍为 `score_v2` 时，可增加独立的配置修订号。

## 14. 衍生指标

衍生指标是基于原始生理数据计算的扩展信息，与上述所有评分规则独立。前测和后测分别独立计算衍生指标；后测结果另外展示前后共同数据口径下的衍生指标变化。

所有衍生指标统一映射到 `0-100`，分数越高表示对应状态越好。正向指标使用：

```text
N_up(x) = clamp((x - L) / (H - L) × 100, 0, 100)
```

反向指标使用：

```text
N_down(x) = clamp((H - x) / (H - L) × 100, 0, 100)
```

`L` 和 `H` 是固定的设备或校准参考范围，不按单个样本动态缩放。某个衍生指标的子项缺失时不记0分，删除该子项后按剩余有效子项的原始权重重新归一化。所有权重和范围均为当前工程初始配置，后续应使用真实配对数据校准。

### 14.1 放松度

放松度使用 HRV、皮电、呼吸和 Alpha 波：

```text
relaxation =
    0.35 × HRV分
  + 0.25 × EDA放松分
  + 0.20 × 呼吸放松分
  + 0.20 × Alpha放松分
```

- HRV 只接受有效 IBI/RR；普通心率不得替代 HRV。
- 没有有效 HRV 时，HRV 子项不计分，其他三个子项按剩余权重重新归一化。
- EDA 使用皮电水平的反向归一化；皮电越低，放松分越高。
- 呼吸使用第4节的目标区间评分，目标区间为 `10-18` 次/分钟。
- Alpha 使用有效 Alpha 值；当设备字段确认是同量纲频段功率时，可改用 Alpha 相对功率。

### 14.2 专注度与专注稳定度

专注度和专注稳定度合并为同一个指标：

```text
attention =
    0.35 × 眼动稳定性
  + 0.25 × 体动稳定性
  + 0.40 × Beta/Theta得分
```

- 眼动稳定性由眼动 `x/y` 坐标的离散程度计算，离散程度越小得分越高。
- 体动稳定性由加速度和角速度的三轴合成幅值计算，运动幅度越小得分越高。
- Beta/Theta 得分由窗口内 Beta 与 Theta 的均值比值计算，比值越高得分越高。
- 任一子项缺失时，其他有效子项按剩余权重重新归一化。
- 没有有效子项时，`attention=null`，并保留缺失原因。

### 14.3 情绪平和度与情绪迁移

情绪平和度使用表情、皮电和心率：

```text
emotion_peace =
    0.50 × 表情平和分
  + 0.25 × EDA平和分
  + 0.25 × 心率平和分
```

- 表情平和分使用第6节七类表情的 `value` 映射，先计算有效记录的平均设备值，再映射到 `0-100`。
- EDA 平和分由皮电水平和波动程度的反向归一化结果构成。
- 心率平和分根据心率相对于目标区间或个体参考基线的偏离程度计算，偏离越小得分越高。
- 表情质量不合格时不计入该衍生指标；其他有效子项按剩余权重重新归一化。
- 该指标不覆盖第3节的 `mood`，表情也不因此成为新的核心状态分项。

前后测的情绪迁移定义为共同数据口径下的差值：

```text
emotion_migration = emotion_peace_after - emotion_peace_before
```

正值表示情绪向更平和方向迁移，负值表示平和度下降。

### 14.4 综合放松指数

综合放松指数是衍生指标的多模态融合结果：

```text
comprehensive_relaxation =
    0.45 × relaxation
  + 0.25 × attention
  + 0.30 × emotion_peace
```

某个一级指标不可用时不记0分，使用其他有效一级指标按原始权重重新归一化。该指数只作为扩展结果输出，不替换 `state_score`，也不改变原有风险等级和推荐输入。

### 14.5 前后衍生指标比较

前测和后测都先按照本节规则独立计算衍生指标。比较时不得直接相减使用了不同数据集合的两个总分，而应先取得共同有效子项：

```text
common_metrics = 前测有效子项 ∩ 后测有效子项
before_common = 按共同子项和原始权重重算前测分数
after_common  = 按共同子项和原始权重重算后测分数
change = after_common - before_common
```

变化百分比为：

```text
change_percent = (after_common - before_common) / abs(before_common) × 100
```

当 `before_common` 缺失、接近0或没有共同子项时，变化百分比为 `null`；没有共同子项时 `comparable=false`。前测输出只包含本次衍生指标，后测输出在 `effect.derived_metrics` 中展示各项的 `before`、`after`、`change`、`change_percent`、共同子项和可比性。该比较不改变第8节已有的核心 `state_change`。
