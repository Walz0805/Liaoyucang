# GitHub Pages

This demo is a static site. It uses bundled demo assessment data, supplied narration and online placeholder video. No local Node server is needed when hosted.

After upload, select Settings → Pages → Source: GitHub Actions. Then run Actions → Publish StarPulse demo → Run workflow. The published URL will appear on the completed deployment.

The workflow is manual so pushing source does not automatically publish it. It deploys only runtime files, excluding preview logs, development scripts and discarded character variants.

Audio starts at the matching experience stage. Browsers may require an initial click. No API keys are required. Future private assessment credentials must be kept on a backend, never in this static site.
